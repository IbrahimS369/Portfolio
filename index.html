01 About

Frontend is where I started. Full-stack .NET is where I'm heading.

I build modern, responsive frontend interfaces — mostly with Angular and TypeScript — and connect them to real data through REST APIs.

I care about the details people actually feel: clean layouts, sensible interactions, accessible markup, and pages that load fast. Right now I'm extending that foundation to the server side with C# and ASP.NET Core, so I can own features end to end.
